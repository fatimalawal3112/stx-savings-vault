# STX Savings Vault

A decentralized savings protocol built on the Stacks blockchain that enables secure STX token deposits and rewards.

## Features

- 🏦 Secure STX token deposits and withdrawals
- 💰 Automated yield generation
- 🔐 Smart contract powered security
- 🌐 Fully decentralized operation

## Installation

```bash
npm install
```

## Configuration

Create your config files in the settings directory:
- `Mainnet.toml` for production
- `Testnet.toml` for testing

## Development

```bash
# Run tests
npm test

# Deploy to testnet 
npm run deploy:testnet

# Deploy to mainnet
npm run deploy:mainnet
```

## Security

This protocol has undergone security audits but all smart contracts carry inherent risks. Use at your own discretion.
